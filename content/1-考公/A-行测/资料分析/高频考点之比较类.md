# 一、比值（增速、比重、基期等）大小比较

>[!note] 用“双线法”进行增速比较
>顾名思义就是画两条线，用两条线之间的距离来代替分数的大小：距离远，分数大；距离近，分数小
>
>![f66d2d4d27e72b36a468ded09ec8ca9.jpg|550](https://lsky.jzyon.top/uplods/202503011044606.png)

替代比较

就是你让我比的东西不好算，我用一个能代替这个东西的、好算的进行比较

| 替代比较思路                 | 原理                                                                                                                             | 什么时候进行代替             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------- |
| 要比年均增长率，用现期量/基期量代替比较   | ∵年均增长率r=$\sqrt[n]{\frac{现期量}{基期量}} -1$ ∴谁$\frac{现期量}{基期量}$大，谁的年均增长率就大。即比年均增长率大小⇿比$\frac{现期量}{基期量}$大小                           | 随时                   |
| 要比增速，用倍数代替比较           | ∵增速r=$\frac{A}{B}-1$，倍数=$\frac{A}{B}$ ∴谁的倍数大，谁的增速就大。即比增速大小⇿比倍数大小                                                               | A和B差距大               |
| 要比部分A/整体，用部分A/部分非A代替比较 | 如果求几个班中那个班男生占比最多，常规比较方法是比$\frac{男}{男+女}$这个分数。如果把$\frac{男}{男+女}$取倒数是$\frac{男+女}{男}$，那通过比谁的$\frac{男}{女}$大，就知道谁的$\frac{男}{男+女}$大了 | 材料给部分A和非部分A，让比部分A/整体 |
| 要比X/A，用X/B代替比较         | ∵$\frac{X}{A}=\frac{X}{B-X}$，一样是取倒数，得出结论是可以用X/B代替比较X/A，反之也可以用X/A代替比较X/B                                                        | 材料给B和X，让比增速大小        |

# 二、增量大小比较

秒杀方法：
- B越大R越大，则X越大（大大则大）
- 我的B是你的N倍，你的R是我的N倍以上（即比N多一点点），我们的X才可能相等（一大一小看倍数）
